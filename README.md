# 🏪 Shop Stock Management System

A simple and practical **Shop Stock Management System** built with **HTML, CSS, and JavaScript**.

The application helps a shop owner manage products, monitor inventory, update stock quantities, and store data in the browser using `localStorage`.

## 🚀 Features

- Add new products
- Prevent duplicate product names
- Validate product information
- Validate buying and selling prices
- Prevent selling price from being lower than buying price
- View all products in a stock table
- Search products
- Filter products by category
- Increase stock with `+ Stock`
- Decrease stock with `− Stock`
- Perform larger stock movements
- Prevent stock from becoming negative
- Delete products
- Display success messages
- Display validation errors inside the page
- Save products to `localStorage`
- Restore products after page reload
- Display inventory statistics
- Identify low-stock products
- Identify out-of-stock products

---

## 🛠️ Technologies

This project uses:

- **HTML5** — page structure
- **CSS3** — styling and responsive design
- **JavaScript (ES6+)** — application logic
- **localStorage** — client-side data storage

No framework or external library is required.
