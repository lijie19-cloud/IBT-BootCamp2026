# 🎓 CampusConnect — Student Community Portal

CampusConnect is a modern and responsive React-based student community portal designed to help students discover campus clubs, explore events, access useful resources, and participate in student activities.

The application demonstrates important React concepts including reusable components, state management, API/data fetching, client-side routing, dynamic routes, Context API, controlled forms, validation, responsive design, and localStorage.
