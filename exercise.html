3. CSS Specificity

This paragraph is red because the ID selector wins.

Specificity:

  • Element selector p = (0, 0, 0, 1)
  • Class selector .special-text = (0, 0, 1, 0)
  • ID selector #important-text = (0, 1, 0, 0)

Therefore, the ID selector has the highest specificity and its red color wins.
