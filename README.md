# Day 17

Project: Day 17 exercises and notes.

## Overview

This repository contains the code, notes, and exercises completed for Day 17 of the learning series. It includes small scripts, examples, and explanations for the topics covered on this day.

## Setup

1. Clone the repo or copy the files to your workspace.
2. Ensure you have Python 3.8+ installed (if examples are Python).
3. Create a virtual environment (optional):

   python -m venv .venv
   .venv\Scripts\activate # Windows

4. Install dependencies if a requirements.txt is present:

   pip install -r requirements.txt

## Usage

- Open the `exercises` or `examples` folder and run the scripts from your terminal.
- Read notes in the `notes` folder for explanations and context.

## Challenges / Goals

- Practice core concepts covered on Day 17.
- Build small, focused examples to reinforce learning.
