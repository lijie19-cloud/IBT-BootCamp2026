# Addis Eats

A simple static Ethiopian food menu built with **React** and **Vite**.

This project demonstrates the basic React concepts of components, props, JSX, arrays, `map()`, keys, and component composition.

## Features

- Header component
- Reusable Dish component
- Dish name and price passed using props
- Menu stored in a JavaScript array
- Menu rendered using `map()`
- Stable `key` for each dish
- Responsive menu layout
- Ethiopian Birr (ETB) prices

## Menu

The current menu includes:

| Dish | Price |
|---|---:|
| Kitfo | 1000 ETB |
| Shiro Wot | 280 ETB |
| Tibs | 1200 ETB |
| Vegetarian Firfir | 550 ETB |
